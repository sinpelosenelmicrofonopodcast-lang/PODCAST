# Editorial y Facebook

Aprobar publica la versión revisada en la web. La casilla «Publicar en Facebook» comienza desmarcada. Solo una versión aprobada con esa casilla marcada, portada y caption válido permite enviar foto y estado a Facebook. El comentario enlaza el artículo ya publicado. El fijado se realiza desde Facebook: no existe una operación documentada de fijado en la integración actual.

EDITORIAL WEB conserva A:O y añade P:U: casilla, caption, estado, URL Facebook, comentario y fijado. Las ediciones de texto reinician la revisión. Una selección y aprobación simultáneas del mismo texto en Sheet se procesan juntas. La web publicada se conserva mientras se revisan cambios posteriores.

La selección y caption quedan vinculados a un hash de aprobación. Hay una entrega por noticia, con identificadores de Meta conservados. Un resultado incierto nunca se reenvía automáticamente. Foto confirmada y comentario tienen reclamaciones independientes; un comentario pendiente puede completarse sin repetir la foto. Un cambio posterior no crea otra publicación automáticamente.

Las credenciales de Meta se transfieren desde la conexión del propietario en Social Manager al servicio editorial mediante el puente autenticado y quedan cifradas. El cron existente comprueba Drive cada minuto. No depende de una sesión de ChatGPT.

Portadas: una plantilla 16:9 negra y naranja, logo oficial sin fondo, región, titular corto y subtítulo; imágenes conceptuales señaladas como «Ilustración editorial». No presentar una ilustración generada como fotografía del suceso.

La portada es necesaria para aprobar desde la web, el agente o Drive. Una portada nueva vuelve a revisión; si la noticia ya estaba publicada, conserva su versión pública hasta aprobar la actualización. El panel avisa cuando la revisión abierta quedó desactualizada.
